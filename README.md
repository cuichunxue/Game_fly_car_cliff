# 絶壁ロードスター（CLIFF ROADSTER）

道を駆け、**絶壁を垂直に駆け上がり**、頂から空へ跳ぶ。
海岸 → キャニオン → 摩天楼 → 雲海 → オーロラ氷壁 → 星の頂。
6つの絶壁を越えて、**標高1000mで夜明け**を迎える 3D クライム・ドライブ。

「スラスト・ロードスター ULTRA」のエンジン（Three.js 描画・Web Audio 合成サウンド）をベースにしています。
設計の考え方は [JOURNEY.md](JOURNEY.md)（ジャーニーマップ）にまとめています。

## 遊び方
`index.html` をブラウザで開くだけ（ビルド不要・オフライン可。Three.js 同梱）。
ローカルで開く場合は簡単なサーバー経由がおすすめです：`npx http-server .`

| 操作 | キーボード | スマホ | ゲームパッド |
|---|---|---|---|
| 噴射（ジャンプ／上昇／**壁で加速**） | Space・↑・W | 右下「噴射」 | A |
| ハンドル | ← → / A D | 画面左側を左右スライド | 左スティック／十字 |
| ブースト | Shift・X | 「BOOST」 | RT・X |
| 一時停止 | P・Esc | II ボタン | Start |

### 絶壁の登り方
1. 「絶壁まで170m」の助走路で**ブーストパッド**を踏んで加速（AIRは壁のために温存）。
2. そのまま壁に突っ込むと、タイヤが食いついて**垂直に登り始める**。
3. 壁では重力で減速。**噴射を長押し**で加速。速度が落ちきると失速して転落。
4. 「▼落石」「◆岩棚」は車線変更でかわす。壁のパッドとAIRセルで燃料補給。氷は滑る。
5. 頂の縁から空へ跳び出す**頂上ジャンプ**。着地直前の短い噴射で**パーフェクト着地**。
6. 空中から壁に飛びつく**ウォールキャッチ**、雲海を突き抜ける瞬間もボーナス。

### スター（各チャプター3つ）
★ 頂上へ ／ ★ ノーミス ／ ★ 頂上ジャンプをパーフェクト着地
頂を越えると、タイトルの**ジャーニーマップ**からそのチャプターに直接挑戦できます。

## 構成
```
index.html          画面・HUD（標高トラック・ジャーニーバナー）
css/style.css       UI
js/textures.js      Canvasによる手続きテクスチャ
js/models.js        車・障害物・景観・絶壁パーツの3Dモデル
js/world.js         チャプター・空・雲海・コース生成・絶壁の形状
js/fx.js            パーティクル・着地ガイド・花火・天候
js/audio.js         サウンドエンジンとBGM（クライム・レイヤー／ドロップ）
js/game.js          物理（道路・壁・空中）・入力・カメラ・進行
js/vendor/          three.js r147（MIT）
JOURNEY.md          ジャーニーマップ設計書
```
